自动解析并填写企业安全合规问卷，支持 PDF、Word、Excel 格式，节省 4-5 小时的手动填写时间。

## 功能特性

- ✅ 支持 PDF/Word/Excel 问卷格式
- ✅ 基于 YAML 模板自动填充答案
- ✅ 智能关键词匹配
- ✅ 导出填写完成的文件
- ✅ 简洁的 CLI 界面

## 工作原理

1. **解析问卷**: 提取 PDF/Word/Excel 中的问题和表单字段
2. **智能匹配**: 使用关键词匹配算法找到对应的答案
3. **填充答案**: 将模板中的企业信息填入问卷
4. **导出文件**: 生成填写完成的新文件

## 支持的问题类型

工具能识别以下常见问题：
- 公司基本信息（名称、地址、联系方式）
- ISO 认证信息
- 数据保护与隐私合规
- 安全策略与流程
- 技术架构与安全措施
- 备份与灾难恢复

## 风险点

1. **匹配准确性**: 关键词匹配可能不完全准确，建议人工复核
2. **格式兼容性**: 某些特殊格式的问卷可能需要手动调整
3. **PDF 表单**: 仅支持带表单字段的 PDF，扫描版 PDF 需要 OCR

## 验证方式

填写完成后，请：
1. 打开生成的文件检查填充内容
2. 确认关键信息（公司名称、认证编号等）正确
3. 补充工具未能自动填写的字段

## 故障排查

**问题**: 没有找到任何问题
- 检查文件格式是否正确
- 确认问卷包含可识别的问题文本

**问题**: 答案未填充
- 检查 `template.yaml` 是否包含对应字段
- 查看问题文本是否包含可匹配的关键词

**问题**: PDF 导出失败
- 确保 PDF 包含可编辑的表单字段
- 尝试使用 Word 或 Excel 格式
